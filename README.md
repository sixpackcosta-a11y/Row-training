## V76 — Registro MAR por bloques

- Corrige el botón **Volver** dentro de Registro MAR.
- Cada ejercicio/bloque de la sesión MAR aparece por separado con sus propios campos de resultado.
- Se guardan varios registros en `sea_results`, uno por bloque, manteniendo el nombre y la prescripción del bloque para poder analizarlos después.
- No requiere SQL nuevo.
